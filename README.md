# Blackjack Trainer

A Python project for blackjack practice.

The project currently includes a Python package and a command-line entry point
that displays the application name and version. Training features are not yet
implemented.

## Requirements

- Python 3.10 or newer

No third-party runtime dependencies are required.

## Run

From the project root:

```bash
python -m blackjack_trainer
python -m blackjack_trainer --version
```
